# 📊 Auspify Data Science Internship

> A comprehensive Data Science internship project focused on Netflix data cleaning, exploratory analysis, recommendation systems, trend forecasting, machine learning classification, and business insights.

## 👨‍💻 Project Overview

This repository contains my work completed as part of the **Auspify Technologies Data Science Internship Program**.

The project uses the Netflix titles dataset to demonstrate an end-to-end Data Science workflow, including:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis
- Recommendation System Analysis
- Trend Prediction
- Machine Learning Classification
- Business Insights Dashboard

The internship task list contains six practical Data Science tasks and requires completion of any four tasks. This repository documents all six task areas implemented in the project.

---

## 🎯 Objectives

The main objectives of this project are to:

- Clean and prepare raw Netflix data for analysis.
- Identify patterns and trends in Netflix content.
- Analyze content distribution across categories and countries.
- Build a basic content recommendation approach.
- Forecast future Netflix content trends.
- Develop machine learning classification models.
- Compare model performance using evaluation metrics.
- Generate business-oriented insights from the data.
- Present results through visualizations and an interactive dashboard.

## 📌 Tasks Completed

### Task 1 — Data Cleaning & Preprocessing

Prepared the Netflix dataset for analysis by:

- Loading the dataset using Pandas
- Checking missing values
- Identifying duplicate records
- Handling missing data
- Converting date-related columns
- Transforming data into analysis-ready format

**Technologies:** Python, Pandas, NumPy

---

### Task 2 — Exploratory Data Analysis

Performed exploratory analysis to identify:

- Content distribution
- Movies vs TV Shows
- Release-year trends
- Top countries
- Popular genres/categories
- Content ratings
- Important patterns in the dataset

Visualizations were created using Matplotlib, Seaborn and Plotly.

**Technologies:** Pandas, Matplotlib, Seaborn, Plotly

---

### Task 3 — Recommendation System

Developed a basic content-based recommendation approach using Netflix content information.

The workflow includes:

- Feature extraction
- Text preprocessing
- Feature representation
- Similarity analysis
- Content recommendations

**Technologies:** Python, Pandas, Scikit-learn, NLP techniques

---

### Task 4 — Trend Prediction

Analyzed historical Netflix content trends and developed a forecasting workflow.

The analysis includes:

- Yearly content trends
- Historical trend analysis
- Forecasting
- Model evaluation
- Future predictions
- Visualization of predicted trends

**Technologies:** Python, Pandas, Scikit-learn, Matplotlib

---

### Task 5 — Machine Learning Classification

Built machine learning models to classify Netflix content into:

- Movie
- TV Show

The project includes:

- Feature selection
- Data preprocessing
- Train/test splitting
- Logistic Regression
- Decision Tree Classification
- Accuracy evaluation
- Precision
- Recall
- F1 Score
- Confusion matrices
- Model comparison

**Technologies:** Python, Pandas, Scikit-learn

---

### Task 6 — Business Insights Dashboard

Created an end-to-end business insights workflow combining:

- Data analysis
- Machine learning
- Interactive filtering
- Visualization
- Business insights
- Predictive analytics

The dashboard provides insights into Netflix content distribution, release trends, genres, countries and classification results.

**Technologies:** Python, Pandas, Plotly, Scikit-learn, Jupyter Widgets

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Auspify-Data-Science-Internship.git
```

### 2. Open the project

```bash
cd Auspify-Data-Science-Internship
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start Jupyter Notebook

```bash
jupyter notebook
```

### 5. Open

```text
notebooks/Netflix_Data_Science_Internship.ipynb
```

### 6. Run the notebook

Run the cells sequentially from Task 1 through Task 6.
